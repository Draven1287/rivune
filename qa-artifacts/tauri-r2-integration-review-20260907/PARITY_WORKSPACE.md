## Three highest-impact restorations

1. **Restore an active Project workspace.** In host.rs define persisted versioned project records, conversation project association, project instructions, and explicit project create/update/archive/link commands; expose bounded DTOs through desktop-host.mjs/core.mjs. In index.html/app.mjs render Projects navigation and project detail using existing Rivune styling. Restore file attachment through explicit native selection and host-validated scoped references, never reactivate archived permissions automatically. First deliver a real vertical path: create project, add instructions/file, start linked chat, choose sharing, reopen with state intact. Behavioral acceptance: save failure preserves edits; archived/imported records cannot silently gain file access; moved/missing/changed files need renewed consent; one project's context cannot leak into another; restart and draft navigation preserve association. Do not copy macOS bookmarks as cross-platform authority.

2. **Restore usable search/navigation.** Add an in-app accessible search field with clear control, no-results state and stable selection. Start with the actual local title/project fields already admitted by the host; if indexing response text, implement bounded host search instead of loading unbounded history into the renderer. Keep this distinct from the other review's history persistence work. Boundaries: app.mjs conversation-list projection, index.html sidebar, optional host search command/core DTO. Acceptance: query typing and clearing cannot rewrite drafts, switching results selects correct conversation, Unicode queries work, keyboard selection/focus stays stable, imported read-only state persists, clear returns prior list scope. Project filter builds on restoration1, not a fake category.

3. **Restore generated-file review and continuation.** Implement a bounded host artifact parser/storage/receipt path grounded in ResponseArtifact and ArtifactContinuation invariants; wire transcript artifact card, file viewer and explicit save/continue actions. Bind artifacts to immutable originating response and content hashes. Use a constrained static preview with untrusted content isolated from host IPC; no automatic script/remote loading. Apply is a distinct explicit operation with conflict detection and rollback evidence, not a model claim. Boundaries: host.rs artifact records/commands, desktop-host/core DTO, transcript.mjs callback wiring and real in-app artifact panel. Acceptance: traversal/symlink/outside-scope paths rejected, altered source hashes block stale apply/continue, failure preserves existing files/drafts, preview cannot call native commands, saved bytes match receipt, continuation includes exact selected revision, no claim tests ran unless the host actually ran them. CLI shell/general-browser execution remains separate until its capabilities and approvals are implemented.

These restore the user's everyday workspace before adding more decorative UI. Full Constellation execution still depends on the separate TEAM_RUNTIME_INTEGRATION_GAP plan. This report does not grant a source edit lease or claim product readiness.
