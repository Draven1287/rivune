FAQ

Practical answers before you try Rivune.

Computers, providers, modes, privacy, and support—without hidden assumptions.

Which computers can run Rivune?

The current native preview is for Macs running macOS 26 or later, on Apple silicon or Intel. Windows and Linux versions are planned, but no verified installers exist yet.

Can I download an installer now?

The Mac installer is still being validated. Developer source preview 4 is available and requires Xcode; it is not a signed installer or DMG. Check current availability →

Do I need provider accounts or API access?

Yes. Rivune connects to supported provider tools. You sign in or configure access with each provider, and that provider controls model availability.

Does Rivune cost money?

Rivune is open-source software and costs $0. Provider subscriptions, API usage, limits, and charges remain separate.

What are Normal AI, Council, and Swarm?

Normal AI uses one selected provider. Council gathers independent answers and has a mediator form one draft. Swarm is intended to let a lead delegate separate subtasks and review the integrated result. Compare the strategies →

Where do conversations and requests go?

Conversation history is local by default. Requests go to the providers used in that conversation. Team strategies may send approved context or successful member answers to the selected mediator or lead. Read exact routing →

Does Rivune work fully offline?

The workspace and local history can remain on your Mac, but connected AI providers usually require internet access. Their own tools, accounts, and service availability still apply.

How do I ask a question or report a bug?

Contact Aarav for questions and feedback, or open a GitHub issue for a reproducible bug. Do not include secrets, API keys, or private conversation content.
