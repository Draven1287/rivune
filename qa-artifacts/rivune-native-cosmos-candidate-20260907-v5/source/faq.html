FAQ

Practical answers before you try Rivune.

Computers, providers, modes, privacy, and support—without hidden assumptions.

Which computers can run Rivune?

Rivune is being rebuilt as one Tauri desktop app for macOS, Windows, and Linux. No Tauri app or installer has been verified on any platform yet. The currently installed Mac app is a separate legacy SwiftUI build.

Can I download an installer now?

No accepted macOS, Windows, or Linux installer exists yet. Developer source preview 4 is legacy SwiftUI Mac code that requires Xcode; it is not the forthcoming Tauri app or an installer. Check current availability →

Do I need provider accounts or API access?

Provider accounts or API access will still be separate from Rivune. The real provider host pipeline is the first Tauri milestone, but no live provider request has been verified in Tauri yet.

Does Rivune cost money?

Rivune is open-source software and costs $0. Provider subscriptions, API usage, limits, and charges remain separate.

What are Normal AI, Council, and Swarm?

Normal AI is planned to use one selected provider. Council is planned to gather independent answers for mediator review. Swarm is planned to let a lead delegate bounded subtasks and integrate reviewed work. None of these workflows is verified in Tauri yet. Compare the strategies →

Where do conversations and requests go?

The legacy Mac build stores history locally by default and sends requests to connected providers. Tauri storage, request routing, and team data sharing still require implementation and verification. Read exact routing →

Does Rivune work fully offline?

The planned desktop workspace may keep local data on your computer, but that behavior is not yet verified in Tauri. Connected AI providers normally require internet access and remain subject to their own accounts and availability.

How do I ask a question or report a bug?

Contact Aarav for questions and feedback, or open a GitHub issue for a reproducible bug. Do not include secrets, API keys, or private conversation content.
