FAQ

Practical answers before you try Rivune.

Computers, providers, modes, privacy, and support—without hidden assumptions.

Which computers can run Rivune?

Rivune is a desktop app in development for macOS, Windows, and Linux. Downloads are not yet available.

Can I download an installer now?

No. Downloads are not yet available for macOS, Windows, or Linux. A developer source preview is available for developers with Xcode, but it is not an installer. Check current availability →

Do I need provider accounts or API access?

Yes. Provider accounts or API access will remain separate from Rivune. Single-AI chat is being built first, and connected AI features are not ready yet.

Does Rivune cost money?

Rivune is open-source software and costs $0. Provider subscriptions, API usage, limits, and charges remain separate.

What are Normal AI, Council, and Swarm?

Normal AI will use one selected provider. Council will gather independent answers for review. Swarm will let a lead delegate separate tasks and combine the results. Single-AI chat is being built first; the team workflows will follow. Compare the strategies →

Where do conversations and requests go?

The legacy Mac build stores history locally and sends requests to connected providers. Storage and data-sharing behavior for the new desktop app is still being developed. Read exact routing →

Does Rivune work fully offline?

The desktop app is not ready yet, so offline behavior has not been confirmed. Connected AI providers normally require internet access and remain subject to their own accounts and availability.

How do I ask a question or report a bug?

Contact Aarav for questions and feedback, or open a GitHub issue for a reproducible bug. Do not include secrets, API keys, or private conversation content.
