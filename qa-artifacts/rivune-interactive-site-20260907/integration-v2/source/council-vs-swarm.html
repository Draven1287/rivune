A guide to Rivune

One team. One lead. The right strategy for the request.

Rivune is a desktop app in development for macOS, Windows, and Linux. Its planned team model uses one conversation and a reusable AI team. You write a normal prompt. The appointed lead proposes how the team should work, Rivune validates that choice, and the lead owns one final answer or deliverable.

Downloads are not yet available. Single-AI chat is being built first; team workflows will follow.

Set up a team once, then start with a prompt

Rivune should propose an eligible team and lead so a first request does not begin with a configuration exercise. You can keep that proposal or adjust the lead, members, models, and supported reasoning settings beside the composer. Multiple members may use the same provider tool with different settings.

The team is reusable. Each request freezes the team and limits it started with, so later edits do not rewrite earlier work. A configured manager and the actual fallback lead can differ; the run record should identify who actually owned the final result.

The lead proposes; Rivune validates

Auto is the target default after both execution paths qualify. The lead returns a structured strategy decision and a brief reason. Rivune then validates available adapters, permissions, team capacity, and the work budget before dispatch.

You can use a supported manual override. If the requested strategy is unavailable, Rivune should explain why and offer an available path.

Constellation gathers independent perspectives

Independent perspectives suit questions that benefit from separate answers: comparing approaches, weighing a decision, or reviewing a proposed solution.

Members receive the same approved context and answer independently, without seeing peer drafts. The appointed lead reviews their contributions and writes one final answer. It can combine, correct, or reject claims; unresolved disagreement should remain inspectable.

Constellation divides real work

Delegated work suits projects with separable tasks. The lead assigns bounded work to real available workers, coordinates review, and integrates the result into one deliverable.

Each worker receives a bounded task, the needed context, and the access you allow. The lead reviews the completed work and brings it into the final deliverable.

What is available now?

The desktop app and installers are not available yet. A developer source preview is available for developers with Xcode, but it is not a downloadable app. Single-AI chat is being built first; Constellation is in development.

Check the developer source preview or the current desktop download status. Earlier Together conversations retain their saved identity and must not be relabeled as new strategy runs.

Provider access and data remain separate

Connected AI features are not available yet. When they are ready, you will need the relevant provider access and permission to use the selected model. Provider terms, limits, and charges apply separately. Unknown model identity or remaining usage stays unknown.

The legacy Mac build stores conversation history locally, while AI requests go to connected providers. Storage and routing for the new desktop app are still being developed. The lead receives participating members' successful answers. Team members should receive only the approved context needed for assigned tasks. A routing decision cannot expand permissions or budgets.
