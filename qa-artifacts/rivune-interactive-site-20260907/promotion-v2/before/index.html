Council & Swarm

Project direction

One proposed team, two ways of working. Keep Rivune’s suggested manager or choose another eligible member and reasoning setting. The planned team can include multiple members using the same provider tool.

Council

First development stage

Independent perspectives.
One reviewed answer.

Members answer the same question independently. The manager reviews their contributions and delivers one final answer.

  1. Independent answers
  2. Manager review
  3. Final synthesis

Swarm

Future milestone

Separate agent tasks.
One integrated result.

The manager assigns separate tasks to real workers, coordinates review, and integrates their work into a usable result.

  1. Delegate tasks
  2. Agent work
  3. Integrate results

The public source preview 4 does not include this configurable team experience. Council is the first development stage; real Swarm execution and automatic workflow selection remain future milestones. Publishing this project page does not make those features available.

Concept overview. This page does not run models or agents.

Before you get started

Your Mac.
Your provider access.

Rivune is the workspace. The AI models come from the providers you connect.

Provider subscriptions, permissions, usage limits, and charges apply separately.

  • A compatible Mac

    {{MAC_REQUIREMENT}}

  • A supported provider connection

    The current source preview supports Codex CLI and Claude Code CLI. Install the tool you want to use and complete that provider’s sign-in. Rivune Settings checks whether it is ready.

  • Access to the models you choose

    Your provider must allow access to the selected model. A free account may not include it. Using Rivune does not grant access or include AI usage.

  • Mode availability

    Source preview 4 predates the proposed team-and-manager experience. Local development is proceeding through Council first; Swarm and Auto are not public release features. Connecting a provider does not enable them.
