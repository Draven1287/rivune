Before you get started

Your Mac.
Your provider access.

Rivune is the workspace. The AI models come from the providers you connect.

Provider subscriptions, permissions, usage limits, and charges apply separately.

  • A compatible Mac

    {{MAC_REQUIREMENT}}

  • A supported provider connection

    The current source preview supports Codex CLI and Claude Code CLI. Install the tool you want to use and complete that provider's sign-in. Rivune Settings checks whether it is ready.

  • Access to the models you choose

    Your provider must allow access to the selected model. A free account may not include it. Using Rivune does not grant access or include AI usage.

  • Workflow availability

    Source preview 4 predates the one-team experience. Council exists only in later local development; real Swarm and Auto are not public release features. Connecting a provider does not enable them.
