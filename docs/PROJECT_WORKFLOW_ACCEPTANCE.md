## Current boundary

ProjectWorkspace.swift implements bounded snapshots, reviewed manifests, guarded file application, structural checks and a JavaScript-disabled preview. It does not implement package installation, shell/build/test execution or a general autonomous development loop. Adding an execution layer requires explicit working-directory, command and network boundaries, cancellation, and captured exit/output records before calling that capability complete.
