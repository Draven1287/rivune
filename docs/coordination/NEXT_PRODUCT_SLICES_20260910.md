## Blockers kept outside the three slices

These are real gates, but they should not stop the unblocked UI work above or be represented as completed:

- **Real provider:** installation discovery and saved route configuration do not prove authentication or a successful response. No live CLI answer was exercised in the accepted saved-result or S02 native receipts. Codex discovery reports are deliberately `selectionEnabled=false`; named model and reasoning controls remain unavailable until authenticated entitlement mapping and exact admission are proven.
- **Restart:** the accepted saved-result commit has not been built or launched natively. Its viewer must survive a real close/reopen with the same frozen answer, selected conversation, and draft before restart behavior is accepted.
- **Release:** a QA bundle or isolated local build is not a distributable release. Signing, notarization, installer/update verification, asset redistribution rights, and remaining notice completeness must close before a public DMG or installed-app replacement.

## Deliberately deferred

- **Auto and Swarm:** current product host behavior is Council; do not label another strategy as executed without a wired runtime and durable admitted record.
- **Exact model/reasoning menus:** discovery transport exists only as disabled, synthetic source groundwork. Do not populate guessed options.
- **Files/editor side pane for native results:** the approved direction allows files and artifacts beside chat when needed, but the current real host snapshot has no durable file/artifact contract. Define that result contract after the three slices above; do not copy the browser demo’s synthetic files into the native app.
- **New settings, agents, terminals, or telemetry:** no current user-visible gap justifies adding these before the core chat and result path is clean.

## Evidence boundary

The accepted saved-result review verifies a local source export and exact 134-file manifest. It explicitly does not verify compilation, native inclusion, whole-layout visual approval, live providers, restart, or release. Current root workspace files can be newer than the isolated `4ae1b21` export; the app owner must reconcile deliberately and preserve the accepted saved-result behavior instead of copying the root tree wholesale.
