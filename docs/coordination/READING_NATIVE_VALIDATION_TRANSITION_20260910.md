## Source basis for the transition

Inspected accepted native main.rs request_quit/complete_shutdown/profile resolution/Reopen/CloseRequested and frontend lifecycle.ts plus workspaceController.ts prepareShutdownDrafts. Window close prevents destruction and hides main. Normal Quit emits a token, renderer freezes and validates dirty drafts, begins shutdown, flushes each with durable receipt validation, then asks host to complete. Pending changes, retry/recovery state or unconfirmed persistence block completion. Native completion awaits host preparation (12-second host timeout), sets ready_to_exit only on success, then exits. That timeout is not permission to force-quit after 12 seconds.

Blocked shutdown retains the window; Stay in workspace asks for acknowledged abort before resuming. Reopen only restores the existing window, except healthy completed shutdown. Recovery's ready flag is permission to exit, not proof of exit intent. These are source observations, not native validation results and not proof older installed/S02 executables contain identical code.

Profile override rejects relative/root/default-alias/symlink/non-directory inputs. If the environment variable is absent, source deliberately uses app-data default instead. Therefore plist presence alone is insufficient runtime proof of the reserved profile. No launch may silently fall back and then be accepted as isolated.
