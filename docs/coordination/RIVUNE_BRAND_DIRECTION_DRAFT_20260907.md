## First visual direction to try

- Graphite foundation, soft white text and restrained cool-blue accent for active states. Candidate palette: background #0B0D11, surface #141820, primary text #F3F5F7, secondary text #AAB2BF, accent #8CB8FF. Verify actual contrast for each use; these are draft tokens.
- Try a freely licensed modern sans family such as Manrope for headings with a readable system sans for body. Verify license and self-host if adopted. No paid fonts. Avoid very tight tracking; let headings breathe. Show the actual rendered typography for approval, not a font-name-only decision.
- Desktop heading around 48–64px and mobile 34–42px, adjusted to layout rather than forced into giant lines. Body roughly 17–18px with comfortable line height. Test actual zoom, narrow widths and long labels.
- Compact navigation, clear active page, readable text and generous click targets. Pages: Home, App, How It Works, FAQ, About/Contact, Download. Use genuine URLs and browser history.
- Bring product interaction into the first viewport at ordinary laptop sizes. Prefer an asymmetric hero with concise copy beside an interactive demonstration. Stack intentionally on mobile.
