# Private security reporting prerequisite

The website source-download review found that SECURITY.md tells recipients to
use the repository Security tab but provides no repository/reporting URL.
The current checkout has no configured git remote, and no verified private
reporting destination was found in README, CONTRIBUTING or the site page.

This is an unmet public-release prerequisite. Before release, the owner must
provide an existing private reporting channel; verify its link, update the site
and source security policy, then rebuild the source ZIP and its checksum.
Do not invent a contact, submit a report, or publish a repository as a workaround.
The existing source ZIP was not changed by this native review.
