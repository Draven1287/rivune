# Rivune product quality direction

Accepted September 12, 2026.

## What we are aiming for

Rivune aims to be an everyday AI workspace with the clarity, craft, responsiveness, and reliability people expect from leading products by Apple, Tesla, Anthropic, and OpenAI. These are quality benchmarks, not affiliations or claims that Rivune has already surpassed them. Rivune should earn repeat use by making useful work effortless.

The visual direction is calm graphite with subtle cosmic atmosphere: a sense of many perspectives and limitless possibility, while keeping conversations readable. Constellation Engine unifies the experience; Council and Swarm are its internal strategies. Single AI remains a clear, equally accessible choice.

## Experience priorities

1. **Simple composer.** Make mode, provider/model, attachments, and Send easy to find. Keep permissions and advanced controls in anchored menus; keep frequent actions visible.
2. **Excellent conversations.** Prioritize readable answers, formatted code, copying, file previews, Edit, Retry, Continue, and predictable scrolling.
3. **Understandable collaboration.** Offer a compact perspectives disclosure showing contributions, agreement, disagreement, and the lead's recommendation. Distinguish authored demonstrations from actual provider responses.
4. **Continuity.** Restore drafts, model selection, workspace, and reading position. Support pinned conversations, searchable history, and archive with Undo.
5. **Trustworthy status.** Show verified account connections and meaningful states: ready, responding, waiting for permission, or disconnected. Put recovery actions beside problems. Progress indicators must represent real progress.
6. **Purposeful native polish.** Use native Liquid Glass where supported for controls, navigation, and menus, with readable content surfaces and accessible fallbacks. Shared UI changes must remain consistent across browser and desktop hosts; CSS effects must not be described as native Liquid Glass.
7. **Fast first success.** Help someone connect one AI and send a first prompt quickly. Introduce advanced features when useful.
8. **Long-session comfort.** Provide keyboard navigation, adjustable text size, accessible contrast, reduced motion, smooth scrolling, and responsive layouts.

## Next implementation priorities

1. Complete a real account/CLI connection through the first in-app reply.
2. Refine the conversation experience and its recovery actions.
3. Make project and agent continuation reliable, including handoff and review status.

Paid API integrations remain mock-tested unless the user explicitly authorizes live paid calls. These priorities describe the intended product, not completed capabilities. Validate each feature in its actual runtime before calling it ready; see [the current preview checkpoint](quiet-preview.md) for implementation limits.
